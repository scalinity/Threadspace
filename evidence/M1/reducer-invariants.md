# M1 reducer invariant catalog

Each invariant names the rule that enforces it and the checks that exercise it. "Monitor" is the per-step invariant monitor in `tests/synthetic/src/runner.rs`, which runs after **every delivered step** of every scenario run, every permutation (10,400) and every SQLite cross-check (1,040, stepwise). "Catalog" is `tests/synthetic/src/scenarios.rs`; "SQLite tests" is `tests/synthetic/tests/sqlite.rs`.

| INV-01 | One namespace + native session ID resolves to one canonical Session | Native key `["session", namespace, native]` in `state-engine/src/keys.rs`; one assignment per key (`identity_assignments` primary key); `sessions UNIQUE(namespace_id, native_session_id)` | Monitor (duplicate session check); `duplicate-deliveries` (10 deliveries each → 1 session); SQLite test `ten_deliveries_…` (3 entries, 3 facts, 1 session) |
